### Miniforge3

We use the miniforge3 conda / mamba environment in this class.  In a terminal in the root directory of this repository, after the base setup above is complete, you should be able to run

```bash
./setup.sh
```

to install miniforge3.  Type space to see the license agreement, and type yes to the questions.

After the install, new terminals should have `(base)` indicating you are in the base configuration.
